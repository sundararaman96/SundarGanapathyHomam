# கணபதி ஹோமம் — Web Invitation

A mobile-first Tamil invitation for **Sundar & Family**.

## Event

- **நிகழ்வு:** கணபதி ஹோமம்
- **தேதி:** திங்கட்கிழமை, 5 அக்டோபர் 2026
- **நேரம்:** காலை 6:00 மணி
- **இடம்:** 1/24 Blair Street, Ripley, QLD 4306

## Invitation flow

1. Temple-style opening page.
2. The large press button uses the **exact Ganapathy image supplied by the host** (`assets/ganapathy-click.jpg`).
3. Tapping it opens the date/time page.
4. A card rises from the maroon envelope and displays the date and time.
5. After about **3.3 seconds**, the app automatically continues to the main invite.
6. A visible **இப்போது அழைப்பிதழை காண** button is also provided as a failsafe.
7. The main invite shows the Ganapathy Homam title and invitation wording.
8. The house photo first appears large, then smoothly shrinks into a clickable thumbnail.
9. Tapping the thumbnail opens the full house photo. Tap × or the dark background to close it.
10. **காலெண்டரில் சேர்** opens Google Calendar.
11. **இடம் பார்க்க** opens Google Maps directions.
12. The invitation ends with **அன்புடன், சுந்தர் & குடும்பம்**.

## Tamil wording used

> இந்த மங்களகரமான நிகழ்வில் எங்களுடன் கலந்து கொண்டு, எங்கள் இல்லத்தை ஆசீர்வதிக்குமாறு அன்புடன் அழைக்கிறோம்.

`எங்களுடன்` and `ஆசீர்வதிக்குமாறு` are the natural written forms here.

## Publish with GitHub Pages

Upload **all files and the complete `assets` folder** to the root of your GitHub repository.

Then open:

**Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save**

Do not rename or move the `assets` folder unless you also update the paths in `index.html` and `styles.css`.
