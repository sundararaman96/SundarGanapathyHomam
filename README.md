# கணபதி ஹோமம் – Interactive Tamil Invitation

A mobile-first interactive web invitation for **Sundar & Family**.

## Event

- **Event:** கணபதி ஹோமம்
- **Date:** Monday, 5 October 2026
- **Time:** 6:00 AM
- **Venue:** 1/24 Blair Street, Ripley, QLD 4306

## Invitation wording

> இந்த மங்களகரமான நிகழ்வில் எங்களுடன் கலந்து கொண்டு எங்கள் இல்லத்தை ஆசீர்வதிக்குமாறு அன்புடன் அழைக்கிறோம்.

This is the polished Tamil wording used in the live invitation.

## Animation flow

1. Temple-style front cover with Vinayagar click seal.
2. Tapping the seal opens the invitation.
3. A date/time card rises from a maroon envelope.
4. The main invitation page appears.
5. The house photo appears large and then smoothly shrinks into a clickable thumbnail.
6. Tapping the thumbnail opens the full house photo.
7. Date, time, venue, Google Calendar and Google Maps buttons follow.
8. The invitation ends with **அன்புடன், சுந்தர் & குடும்பம்**.

## Hosting

### GitHub Pages

Upload all project files to the repository root so `index.html` sits at the top level. Then go to **Settings → Pages → Deploy from a branch → main → / (root)**.

### Netlify

Drag and drop the complete project folder into Netlify, or connect the Git repository. No build command is required.
